# Asset sources

- **Fonts** (subset to Latin, embedded in the SVGs as base64 WOFF2): Bricolage Grotesque, Figtree and JetBrains Mono, from github.com/google/fonts (ofl/). SIL Open Font License 1.1.
- **Tech icons**: Simple Icons, github.com/simple-icons/simple-icons, commit 98820a4 (2026-10-04). CC0 1.0. Brand marks remain trademarks of their owners. A few marks are drawn on an inverted tile where the brand colour would be too faint.
- **Illustrations** (developer at the desk, mini scenes, ID card, paper plane, light bulb): drawn for this profile.
- **LinkedIn, portfolio and email icons**: generic briefcase, globe and envelope glyphs drawn for this profile.
- **Portrait** on the ID card: supplied by the profile owner.
- **Contribution snake**: generated daily by the Platane/snk GitHub Action from the live contribution graph.
